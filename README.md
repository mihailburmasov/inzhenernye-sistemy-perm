# Инженерные системы (Пермь)

Сайт ООО «Инженерные системы» — строительство и монтаж инженерных сетей в Пермском крае:
трубопроводы, водоснабжение и водоотведение, газоснабжение, нефтепроводы, ГНБ.

## Стек

Статический HTML + CSS + JS без сборки. Обработка заявок — `send.php` (обычный PHP-хостинг).

```
index.html                        главная
politika-konfidentsialnosti.html  политика конфиденциальности (152-ФЗ)
css/style.css                     все стили
js/main.js                        меню, лайтбокс, форма, cookie-баннер
send.php                          приём заявок (honeypot + проверка согласия)
img/                              изображения (WebP)
fonts/                            Days One + Inter (локально, без Google CDN)
```

## Вёрстка

Размеры заданы в единицах макета (десктоп нарисован на ширину 2083) через переменную `--u`
в `:root`, поэтому на 1920 страница выглядит как макет, а на 1440/1280/планшетах
масштабируется пропорционально. Брейкпоинты: 1180 (планшет), 767 (мобильная вёрстка),
420 и 340 (узкие телефоны).

## Перед публикацией на боевом домене

- `send.php` — указать адрес получателя заявок в переменной `$to` (сейчас `info@n159.ru`).
- Если домен отличается от `n159.ru` — обновить `canonical`, Open Graph, `sitemap.xml`,
  `robots.txt`, JSON-LD и адрес отправителя `$fromEmail` в `send.php`, иначе письма уйдут в спам.
- Заменить заглушки благодарственных писем в `index.html` (блок помечен комментарием)
  и открыть кнопку «Смотреть все письма».

На GitHub Pages форма не работает — там нет PHP, это только превью вёрстки.
